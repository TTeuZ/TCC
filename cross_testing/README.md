# Cross Testing
This script performs a cross testing process with both PKlot2.0 and CNRPark-EXT and summarizes the results to get a clear view.

The cross testing process is based on repeating the train -> validate -> test process 10 times. The first step (first 5 times) uses the first dataset as train/val and the second dataset as test, and in the second step (remaining 5 times) we invert those datasets.

Details about how the train -> validate -> test process works can be found in the main.py script

## How to reproduce
- If necessary, crop all images from the new dataset (PKLot2.0 and CNRPark-EXT)
    - In order to do that, run the script generate_dataset.py, look into the code for more details.
- Run the script run.py

## Notes
- Paths may be changed in the code.
- Each run of the main.py creates a .json file that contains more information about that specified run.
- In order to test different models, you only need to create a wrapper class inside the models folder (follow the MobileNetV3.py class as example) and send it as the model in the run.py.

## Structure
- main.py: Heart of the cross testing;
- run.py: wrapper script to encapsulate the entire cross testing process;
- summary.py: script responsable to summarize the results;
- dataset/data_loader.py: Specific data_loader class for the cross testing;
- dataset/data_leveler.py: Specific data leveler class for the cross testing (random dropout of the smallest class);
- dataset/sample_generator.py: generator class used in the training loop. Its responsable to get the sample that will be use in the training epoch;
- configs: folder with configuration files for cross testing.

Notes: All files that start with '_' contains files generated by the script.
