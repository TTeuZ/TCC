# Resources folder
Already trained models used in the labeling pipeline. here you can put fathers models and base models.

## Structure
This folder may contain 2 sub-folders:
- fathers
- base

### Fathers
Here you can add your fathers models that will run in the labeling pipeline. You can organize in the way you prefer, just remenber to put the correct path in the config run json.

### Base
Here you can add your base models that will be used as initial weights to your son models created in the pipeline. You can organize in the way you prefer, just remenber to put the correct path in the config run json.
