# Activity
This activity is a study guide for Machine Learning basics. The processes covered here goes from feature extraction to machine learning models development.

## Dataset
The PKLot dataset was used.

## Activity steps
The steps to complete the activity are:

1. Crop all parking lot images by hand to obtain all parking spaces;
    -  Compare it with the given images to assert correctness;
2. Use LBP to extract a 256 long feature vector;
3. Create an CSV file containing all the feature vectors for all 700k parking space images;
4. Split the generated data into training and test using an well defined protocol defined by you;
5. Normalize the date using the min/max rule;
6. Create an K-NN by hand with an fixed K = 3;
7. Compute accuracy, confusion matrix by hand;
    - Use the already develop methos do compute those infos to verify your code;
